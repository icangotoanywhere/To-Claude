## 新功能：在桌面放一个「Claude」图标

「使用提示」里新增按钮「在桌面创建 Claude 图标」。点一下，桌面上多一个名为「Claude」的图标：

- 样子就是手机上 Claude App 自己的图标（向系统要来的，不是我们画的），角上有系统加的 To Claude 小标，和原版区分开；
- 点它先弹出网络检查，确认后再打开 Claude；
- Claude 升级换了图标，打开一次 To Claude 就会自动跟上。

有了它，原版 Claude 图标和 To Claude 自己的图标都可以收进应用抽屉或文件夹，平时只用这一个。

如果点了按钮桌面上没出现，请在系统设置 → 应用 → To Claude → 权限里，允许「创建桌面快捷方式」。
